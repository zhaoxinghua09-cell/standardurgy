**Standardurgy** is the methodology for creating standards. A standard is not the product of committee voting but of strength-tiered judgment — **L0 declaration, L1 demonstration, L2 evidence, L3 proof, L4 sustained proof** — governed by three laws: Registered (numbering and version), Verified (judgment criteria testable), Gated (revision gated and audited).

## When to use

Use when creating or escalating a standard, specification, or judgment-tier claim (L0-L4).

## Definition

A standard answers "why is this credible?" through strength tiers rather than voting. Each tier raises the evidence bar; each revision passes through a gate and leaves an audit trail.

## Verification

Prior-art search v2: zero conflicts. Distinct from ISO process: Standardurgy answers "why a standard is credible" via strength tiers and three-law governance.

## Examples

Tier + three-law checklist:

```markdown
- [ ] Tier: which layer (L0/L1/L2/L3/L4) does this claim occupy
- [ ] Registered: unique number + version, traceable
- [ ] Verified: criteria testable/falsifiable, not just a stance
- [ ] Gated: revisions pass a gate, audit trail kept
- [ ] Upgrade path: what evidence is needed for the next tier
```
