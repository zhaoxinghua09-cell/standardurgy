# Standardurgy · 标准工程术

> 主张：标准制定是强度工程——判据从 L0 声明逐层升到 L4 持续证明
> 家族：LGD 创造术元层（-urgy）｜ 状态：占位声明（查重全维度 0 占用，R1+R2）

## 定义
创造标准的方法论：标准不是委员会投票的产物，是判据强度分层（L0 声明/L1 演示/L2 证据/L3 证明/L4 持续证明）的工程。标准要有籍（编号与版本注册）、有证（判据可验证）、有门禁（修订过门禁且留痕）。

## 升层路径
L0 声明 → L1 演示 → L2 证据链 → L3 形式化 → L4 持续证明；任何标准可定位在某一层，并可被要求升层。

## 与 ISO/标准化流程的区隔
ISO 流程回答"标准怎么组织生产"；Standardurgy 回答"标准凭什么可信"——判据强度分层 + 三律治理。
